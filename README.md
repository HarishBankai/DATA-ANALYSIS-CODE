## 📝 About This Repository
This repository contains the coursework, coding exercises, and projects completed during the **[Data Analysis Bootcamp: Master Data Science Skills](https://www.udemy.com/course/data-analysis-bootcamp-master-data-science-skills)** on Udemy.

The focus of this repository is to demonstrate proficiency in the entire Data Science pipeline—from data cleaning and manipulation to statistical analysis and visualization.

## 🛠️ Technologies & Tools
* **Language:** Python 3.x
* **Core Libraries:**
    * `Pandas` (Data Manipulation & Cleaning)
    * `NumPy` (Numerical Computing & Vectorization)
    * `Matplotlib` & `Seaborn` (Data Visualization)
* **Environment:** Jupyter Notebooks / Anaconda

## 📚 Key Topics Covered
### 1. Data Handling with NumPy
* Creating and manipulating N-dimensional arrays.
* Linear algebra operations and broadcasting.
* Statistical computations (Mean, Median, Variance).

### 2. Data Analysis with Pandas
* **DataFrame Operations:** Indexing, selection, and filtering.
* **Data Cleaning:** Handling missing values (`NaN`), duplicates, and type conversion.
* **Aggregation:** Using `.groupby()`, pivot tables, and multi-indexing.
* **Merging:** Concatenating, joining, and merging datasets (SQL-like operations).

### 3. Data Visualization
* **Matplotlib:** Creating static line plots, bar charts, and subplots.
* **Seaborn:** Statistical plots like Heatmaps, Pair Plots, and Box Plots for EDA (Exploratory Data Analysis).
